# Content-Rating-Fragebogen (Play Console)

Antworten für **Play Console → App-Inhalte → Content-Rating**. Der Fragebogen wird
von der IARC gestellt und daraus die Altersfreigaben für alle Regionen (USK, PEGI,
ESRB, …) abgeleitet.

> **Verantwortung:** Die Antworten gibt der Betreiber ab. Falsche Angaben können
> zur Sperrung der App führen. Bitte gegenlesen.

## Kategorie

**Spiel** → Unterkategorie **Denkspiel / Puzzle**.

## Gewalt

| Frage                                          | Antwort |
| ---------------------------------------------- | ------- |
| Enthält die App Gewaltdarstellungen?           | Nein    |
| Realistische Gewalt gegen Menschen oder Tiere? | Nein    |
| Gewalt in einem Fantasy-Kontext?               | Nein    |
| Blut oder Verstümmelung?                       | Nein    |
| Darstellung von Waffen?                        | Nein    |

## Sexualität

| Frage                                      | Antwort |
| ------------------------------------------ | ------- |
| Sexuell anzügliche Inhalte oder Nacktheit? | Nein    |
| Anspielungen sexueller Natur?              | Nein    |

## Sprache

| Frage                           | Antwort |
| ------------------------------- | ------- |
| Vulgäre oder anstößige Sprache? | Nein    |

## Kontrollierte Substanzen

| Frage                                                    | Antwort |
| -------------------------------------------------------- | ------- |
| Darstellung oder Verweis auf Drogen, Alkohol oder Tabak? | Nein    |

## Glücksspiel

| Frage                                                 | Antwort |
| ----------------------------------------------------- | ------- |
| Simuliertes Glücksspiel?                              | Nein    |
| Echtgeld-Glücksspiel?                                 | Nein    |
| Lootboxen oder zufällige Belohnungen gegen Bezahlung? | Nein    |

_Begründung: Belohnte Videos geben eine **feste** Zahl Tipps (3), kein Zufall im
Spiel._

## Interaktive Elemente

| Frage                                                      | Antwort |
| ---------------------------------------------------------- | ------- |
| Können Nutzer miteinander interagieren oder kommunizieren? | Nein    |
| Teilt die App den Standort mit anderen Nutzern?            | Nein    |
| Können Nutzer personenbezogene Daten mit Dritten teilen?   | Nein    |
| Ermöglicht die App den Kauf digitaler Güter?               | Nein    |
| Enthält die App Werbung?                                   | **Ja**  |
| Nutzergenerierte Inhalte?                                  | Nein    |

## Sonstiges

| Frage                                                       | Antwort |
| ----------------------------------------------------------- | ------- |
| Enthält die App Inhalte, die Angst oder Schrecken auslösen? | Nein    |
| Verweise auf Diskriminierung oder Hass?                     | Nein    |
| Verweise auf Selbstverletzung oder Suizid?                  | Nein    |

## Erwartetes Ergebnis

Bei diesen Antworten ist die niedrigste Freigabestufe zu erwarten
(USK ab 0 Jahren, PEGI 3, ESRB Everyone), mit dem Zusatz **„Enthält Werbung"**.

## Werbeeinstellungen an anderer Stelle

Zusätzlich muss in der Play Console unter **App-Inhalte → Werbung** die Angabe
„Diese App enthält Werbung" gesetzt werden. Die Angabe im Content-Rating ersetzt
das nicht.
